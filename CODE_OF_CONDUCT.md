# Code of Conduct

This project is part of the Bioconductor community and follows the
**[Bioconductor Code of Conduct](https://bioconductor.org/about/code-of-conduct/)**
in full. The canonical, versioned text (including translations) is maintained
by the Bioconductor Code of Conduct Committee at
[bioconductor.github.io/bioc_coc_multilingual](https://bioconductor.github.io/bioc_coc_multilingual/).

In short: we are committed to a welcoming, supportive, harassment-free
experience for everyone, regardless of background or identity. Be respectful in
issues, pull requests, and reviews here just as anywhere else in the project.

## Reporting

Concerns about behavior in this repository can be reported to the Bioconductor
Code of Conduct Committee at <code-of-conduct@bioconductor.org>; the reporting
process and the committee roster are described in the canonical document above.
